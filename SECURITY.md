# Security Policy

## Reporting a concern

Do not publish API keys, access tokens, passwords, cookies, personal information or private media in issues or pull requests. Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, contact the repository maintainer through the private contact method listed on their GitHub profile.

## Scope

This repository primarily contains agent instructions and supporting scripts. Review third-party code before running it, keep dependencies current, and restrict local/API permissions to the minimum required. Never commit credentials or production user data.

## Safe automation

Skills that interact with connected social accounts must require explicit human approval before posting, scheduling, sending, deleting or changing account settings.
