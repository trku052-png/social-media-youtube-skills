# 🎯 Social Media & YouTube — Starter Pack

<sub>13 starter packages · Full source packages preserved</sub>

A compact foundation for creator strategy, YouTube growth, Shorts, TikTok, Instagram, hooks, calendars, research, analytics and creator monetization.

## How to use this collection
1. Search the package names and open the package directory that matches your task.
2. Read the complete `SKILL.md` before using the workflow.
3. Check the same folder for `references/`, `scripts/`, `assets/`, templates and examples.
4. Install only the files required by your chosen agent and keep their relative paths intact.
5. Test on a copy or non-sensitive sample before using production media or connected accounts.

## Package structure
Every package keeps its supplied files and folder structure. The `SKILL.md` describes the trigger and workflow; supporting folders may contain commands, reference documents, source files, templates or other dependencies.

## Important notes
- Package capabilities differ: some are instructional, others expect a local application, API, MCP server, account, subscription or runtime.
- The package description is a discovery aid, not a guarantee that a service is available or a skill is installed.
- Keep original assets and credentials safe; never upload API keys or private media to the repository.
- Review media rights and attribution, and require explicit approval before posting or modifying an external account.
