# Creator Launchpad — The Surprise Starter Kit 🚀

A practical mini-playbook for turning this library into a repeatable content system. It is a starter framework, not a promise of views, followers or revenue.

## The 45-minute idea-to-brief sprint
| Time | Action | Output |
|---:|---|---|
| 0–5 min | State the audience and one problem | Audience + problem statement |
| 5–12 min | Review audience questions, search intent and competitors | Evidence notes |
| 12–20 min | Select one content angle and one promise | Creative brief |
| 20–30 min | Write three hooks and a structured outline | Hook set + outline |
| 30–38 min | Plan key shots, B-roll and sound | Shot list |
| 38–45 min | Define thumbnail, title and success metric | Packaging + measurement plan |

## The five-stage production board
1. **Plan:** audience, topic, research, channel fit and goal.
2. **Write:** hook, script, storyboard, CTA and title/thumbnail pairing.
3. **Produce:** footage or generated assets, voice, music, graphics and B-roll.
4. **Polish:** pacing, captions, audio mix, color, export and final QC.
5. **Publish & learn:** metadata, platform formatting, comments, analytics and next experiment.

## 15 reusable prompt starters
1. **Channel audit:** “Audit this channel using only the supplied evidence. Separate observations, hypotheses and unknowns; end with three prioritized experiments.”
2. **Audience map:** “Map the audience into needs, questions, objections and desired outcomes. Do not invent demographic data.”
3. **Content pillars:** “Propose five repeatable content pillars with audience value, formats and example topics.”
4. **Trend scan:** “Find timely public trends in this niche. Include links, dates, evidence and why each trend fits or does not fit this brand.”
5. **Competitor gap:** “Compare these channels by topic, packaging, format and audience promise. Identify gaps without copying their work.”
6. **Video concept:** “Generate ten distinct video concepts, each with audience, promise, proof, format and risk.”
7. **Hook lab:** “Write 12 hooks for the same idea using different structures. Avoid unsupported claims and clickbait.”
8. **Long-form outline:** “Turn this brief into a retention-aware outline with open loops, examples, transitions and a satisfying close.”
9. **Shorts repurpose:** “Find self-contained moments in this source that can become original short-form clips. Return timestamps and context.”
10. **Shot list:** “Translate this script into a shot list with framing, movement, visuals, B-roll and on-screen text.”
11. **Audio plan:** “Propose a dialogue-first sound plan with ambience, SFX, music entry/exit and loudness checks.”
12. **Thumbnail brief:** “Create three contrasting thumbnail concepts with one focal point, short copy and a clear emotional cue.”
13. **Export QA:** “Inspect this export against the brief. Report exact technical values, defects and pass/warn/fail reasons.”
14. **Publishing pack:** “Prepare titles, description, chapters, tags and platform-specific copy; mark anything that requires human verification.”
15. **Analytics review:** “Explain the likely bottleneck using only this performance data and propose one measurable next test.”

## Pre-publish checklist
- [ ] Does the opening make the audience and promise clear?
- [ ] Does the content deliver what the title and thumbnail promise?
- [ ] Are all claims supported and appropriately qualified?
- [ ] Are voice, music, ambience and SFX balanced?
- [ ] Are captions readable, synchronized and proofread?
- [ ] Is the export correct for the target platform?
- [ ] Are media rights, consent and attribution checked?
- [ ] Has a human approved the exact post and destination?

## Post-publish learning loop
Record the baseline, note the date and compare like with like. Look for one bottleneck (impressions, click-through, retention, completion, saves, comments or conversions), propose one change and test it without changing everything at once.
