# Licensing, Attribution & Provenance

This is a mixed-source repository. **There is no single license that automatically applies to every file.**

## How to interpret license information

- The root `LICENSE` applies only to the 13 project-authored social-media and YouTube skills under `skills/` and original project documentation.
- The 26 verified upstream skills retain the license and attribution terms recorded in [manifest-verified-26.json](../manifest-verified-26.json) and [Third-Party Notices](../THIRD_PARTY_NOTICES.md).
- `caption-styling` and `audio-ducking` declare CC-BY-4.0 for the skill text; associated scripts may have a separate license.
- Photoshop Expert includes an additional attribution requirement in the source notes.
- The inspected `video-editagent` source snapshot had no root LICENSE; its redistribution status is unverified.
- The `skills/upstream/` folder contains historical snapshots and should be reviewed against the original sources before reuse.
- Separate assets, fonts, models, footage, music, API terms and platform terms may have independent restrictions.

## Missing license declarations

If a package does not state a license, treat reuse and redistribution permissions as unverified. A missing license is not an open-source grant and is not permission to reuse.

## Before publishing or redistributing

Confirm that you have the right to republish each package. Where the origin, author or license cannot be determined, verify it with the original author or repository owner. Keep copyright statements and required attribution intact.
