# Licensing, Attribution & Provenance

This repository combines project-authored skills with third-party skill packages. **There is no single license that automatically applies to every file.**

## How to interpret license information

- The root `LICENSE` applies only to the project-authored starter content identified there; it does not relicense third-party materials.
- For imported packages, inspect the package’s own `LICENSE` file and the `license` field in its `SKILL.md` frontmatter.
- If no license is stated in the package, treat reuse and redistribution permissions as **unverified**. A missing license is not permission to reuse.
- Separate assets, fonts, model weights, footage, music, API terms and platform terms may have separate restrictions.
- Source skill text is preserved as supplied; do not assume the package is executable or complete simply because it is present here.
