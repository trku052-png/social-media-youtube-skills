# Hooks, Scripts, and Captions
- Identify audience, topic, platform, desired action, and tone.
- Generate hooks using problem, curiosity, contrast, demonstration, story, or myth-busting angles.
- Build a coherent body that pays off the hook with concrete examples.
- Use conversational language and remove filler.
- Adapt captions and CTAs for each platform rather than copying identical text everywhere.
Deliver 5–10 hooks, one recommended script, caption variants, CTA options, and on-screen text.
Never use deceptive clickbait or copied creator scripts.
