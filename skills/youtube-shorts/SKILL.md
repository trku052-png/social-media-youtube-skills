# YouTube Shorts
- Choose one idea with a clear, fast payoff.
- Generate 3–5 distinct opening hooks.
- Structure: hook → context → value/escalation → payoff → optional loop or CTA.
- Write for mobile and sound-off viewing; include visual actions and concise on-screen text.
- Suggest a searchable title and concise description.
Output timed beats with spoken words, visuals, text, and edit notes.
